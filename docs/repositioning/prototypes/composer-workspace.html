About this prototype

A design exploration of one unified, canvas-first workspace. It is a single page with no production code, no model and no network calls.

Functioning

  • Panel layout: collapse, resize by pointer or keyboard, one side panel at a time below 1440 px, canvas first on a phone.
  • One selection shared by canvas, structure tree and inspector.
  • Edits to text and parameters, with undo, redo, history and a comparison of any two versions.
  • Scenario switching: a small expander on this page rebuilds the surface from data and picks the state.
  • Rule checks computed on this page. An edit or a data set that breaks a rule is refused and the last valid surface stays.
  • Playground: every change is a new surface; entered values and focus are carried across; stale and repeated consequential actions are refused.
  • Publish checks and the Agent view's instantiate step, both computed by the same expander.

Simulated

  • The agent and its tools in the Playground. Responses are fixed per scenario, as they will be in the product's Playground.

Staged

  • The conversation. Suggested refinements apply prepared edits; nothing is generated.
  • The plan, the package download, the MCP configuration and the verification levels.
  • Tool names and message shapes. They follow the proposal and A2UI 0.9.1 in outline only.
  • Library and Design system are thin stubs that show what lives there.

The expander and rules here were written for this page and are modelled on the Astryx sample. They prove nothing about dspack-gen, dspack-emit or any renderer.
